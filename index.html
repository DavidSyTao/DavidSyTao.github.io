项目

VLA + 强化学习

面向电柜巡检的 π0.5 + RL Token 精密插入强化学习

  • 冻结 π0.5 基础策略，从其多模态隐藏状态提取 RL Token，驱动轻量 Actor-Critic 进行局部动作精修（Piper、Jetson AGX Orin）
  • 通过关键阶段重置将 RL 聚焦于精细对准 + 插入阶段，仅采集约 60 条关键片段轨迹
  • 在失败发生前引入定向人工介入，为 critic 构建更均衡的成功/失败与纠错样本
  • 样本高效的 off-policy RL 在 40 次真机测试中将插钥匙成功率由 7.5% 提升至 92.5%
VLA · 异步控制 · 真机部署

π0.5 VLA 真机抖动诊断与异步连续控制优化

  • 构建六维真机抖动诊断流程（现象 → 数据 → 策略输出 → 底层控制 → chunk 时序 → 视觉/通信），区分 chunk 内抖动与 chunk 间不连续
  • 在 LeRobot / LIBERO 上对 RTC / T-RTC / VLASH 做不同延迟对比；延迟增大时 VLASH 的未来状态感知最稳定
  • 以时序延迟增强异步训练 VLASH，并提前（约 step 42）启动推理，在约 267ms 重叠窗口内隐藏延迟
  • 在 Piper + Jetson AGX Orin 上将任务成功率由 5% 提升至 65%，平均控制周期由 5123.4ms 降至 224.5ms，任务时间由 51s 缩短至 18s（约 2.8× 加速）
VLA · 参数高效微调 · 算法研究

π0.5 VLA 全参/LoRA 微调、Adapter Capacity 与 Flow Sampling 研究

  • 用 JAX Policy Server + 客户端闭环复现 LIBERO 基准（约 2000 次 rollout）；双 H200 FSDP 全参 SFT 平均成功率 96.55%
  • 建立低成本 LoRA 基线（GPU-hour 约为全参 SFT 的 1/28–1/30）；30K-step LoRA 主配置平均成功率达 97.0%
  • LoRA rank 消融（PaliGemma 4/8/16/32/64）：Long-Horizon 对 adapter 容量最敏感，+23.2 pct（30.0% → 53.2%）
  • Flow-matching 步数消融显示约 5 步后成功率饱和（1/3/5/10 步：95.9/96.6/97.0/96.9%）
  • 16 个失败 episode 的人工归因：抓取精度占主导（8/16）；剩余瓶颈在于局部操作精度而非序列失败
